# 3D Image Gallery

## Overview
The **3D Image Gallery** is a sophisticated web application designed to showcase images in an interactive, 3D carousel format. Built with HTML, CSS, and JavaScript, it offers a dynamic and visually appealing experience with smooth animations and responsive design, ideal for portfolios, galleries, or creative showcases.

## Features
- **🔄 3D Carousel Effect**: Images rotate in a 3D space for an immersive viewing experience.
- **🖱️ Interactive Navigation**: Drag or click to explore images seamlessly.
- **📱 Responsive Design**: Optimized for desktops, tablets, and mobile devices.
- **🛠️ Highly Customizable**: Easily modify images, styles, and animations.
- **🎨 Modern Aesthetics**: Clean, professional design with smooth transitions.

## Installation
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/The-Roshan/3d-gallery.git
   ```
   Or download and extract the ZIP file.

2. **Navigate to the Directory**:
   ```bash
   cd 3d-gallery
   ```

3. **Run the Application**:
   - Open `index.html` in a browser.
   - For development, use a local server (e.g., `python -m http.server` or VS Code Live Server).

## Usage
- **View the Gallery**: Open `index.html` to explore the 3D carousel.
- **Interact**: Drag or click to rotate the gallery (based on `script.js` functionality).
- **Customize Images**: Replace `beggar1.jpg`, `beggar2.jpeg`, etc., with your images in the project folder and update `index.html`.
- **Style Adjustments**: Modify `style.css` for carousel size, colors, or animations.
- **Enhance Functionality**: Edit `script.js` to tweak rotation speed, add auto-rotation, or include keyboard controls.

## Dependencies
- **None**: Uses vanilla HTML, CSS, and JavaScript.
- **Image Files**: Ensure all images referenced in `index.html` are in the project directory.

## Customization
- **🖼️ Images**: Update `<img>` tags in `index.html` with new image paths.
- **🎨 Styling**: Adjust `style.css` for carousel dimensions, colors, or animation effects.
- **⚙️ Interactivity**: Modify `script.js` to change drag sensitivity, add transitions, or implement new features.

## Browser Compatibility
- Compatible with modern browsers:
  - 🌐 Google Chrome
  - 🦊 Mozilla Firefox
  - 🖥️ Microsoft Edge
  - 🍎 Safari
- JavaScript must be enabled for full functionality.
